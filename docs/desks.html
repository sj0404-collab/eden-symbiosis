Почему без пароля

Раньше Windows отдавался по RDP: адрес, логин, пароль — и отказ LOGON_FAILED_UPDATE_PASSWORD при любом способе завести учётную запись. Теперь оба стола — обычные веб-страницы: VNC предлагает тип безопасности 1 (None), предъявлять нечего. Клиент не нужен, вводить нечего.
Обратная сторона честно: кто знает адрес — тот управляет столом. Адрес случайный, живёт до конца сессии и не дольше шести часов.
