Почему RDP не открывается прямо здесь

Браузер не умеет открывать обычные TCP-соединения — только HTTP и WebSocket. RDP это сырой TCP, поэтому веб-страница физически не может к нему подключиться без шлюза-посредника (Guacamole, Myrtille), а шлюз — это отдельный сервер, которого у нас нет.

Поэтому здесь: кнопка, которая передаёт адрес и пароль сразу в Microsoft Remote Desktop, и копирование в один тап. Для Linux-сессии экран показывается по-настоящему — noVNC работает по HTTP и встраивается.
