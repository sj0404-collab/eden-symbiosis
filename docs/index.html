Доступ

Хранится только в этом браузере (localStorage) и уходит исключительно на api.github.com. Нужны права repo и workflow.

Запустить

Любая сессия убивается через 6 часов — это лимит платформы, не настройка. Всё, что не выгружено с раннера, пропадает вместе с ним.

Сессии

загрузка…
Постоянный адрес: filly-above-terrapin.ngrok-free.app — не меняется между запусками. Пароль печатается в сводке запуска; ссылка из сводки подставляет его сама.
Кнопка сама запускает сессию, ждёт туннель и открывает opencode — его собственный веб-интерфейс, ставить на телефон нечего. Заходить на GitHub не нужно.
Всё, что opencode пишет, коммитится в ветку opencode-work каждые 2 минуты и ещё раз при завершении. Сессия закончилась или телефон перезагрузился — файлы уже в репозитории, следующая сессия продолжит ту же ветку.
Несколько сессий работают одновременно — переключайтесь, открывая нужную строку. Свободный ngrok даёт один туннель за раз, поэтому рабочий стол активен только у одной сессии.

Как подключиться с телефона

SSHTermux (pkg install openssh), JuiceSSH или ConnectBot. В логе шага есть и веб-ссылка — открывается в браузере без клиента.
Рабочий столПросто ссылка в браузере, ставить нечего. Адрес постоянный: filly-above-terrapin.ngrok-free.app. Рекомендуется.
RDPMicrosoft Remote Desktop или aFreeRDP. Адрес меняется при каждом запуске: на бесплатном ngrok постоянный домен работает только по HTTP, а RDP — это TCP.
МышьПо OTG работает в обоих режимах. В RDP касание экрана тоже действует как мышь.
